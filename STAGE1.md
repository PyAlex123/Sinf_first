## 1. Цель этапа

Живая демонстрация идеи директору и учителям **на настоящем уроке автора** — «1 класс, II четверть, урок 10» — за 10 минут и на любых устройствах с браузером. Что видят зрители:

1. Учитель запускает урок, первоклассники входят: выбирают своё имя и вводят код из картинок.
2. Слайды листаются у всех одновременно, кнопка «Внимание!» закрывает экраны.
3. Дети проходят тренажёры урока, а учитель в реальном времени видит, кто где и сколько у кого звёзд.
4. На практике в Paint шаги идут синхронно на проекторе и у детей, учитель ставит звёзды за рисунок.
5. Живая викторина с картинками и озвучкой, рейтинг на проекторе.
6. Звёзды и посещаемость уходят в журнал.

Демо работает в двух вариантах:
- **на хостинге с HTTPS**: ссылка открывается на любом устройстве, доступны все функции;
- **на ноутбуке учителя в локальной сети школы, без интернета**: всё, кроме функций экрана (им нужен HTTPS).

**Только вымышленные ученики**: класс 1А из 20 вымышленных детей. Реальные данные детей на этом этапе не храним. Контент уроков — авторский, принадлежит автору проекта.

## 2. Исходные материалы автора (разобраны заранее)

Автор кладёт два файла в `content-src/1-klass-2-chetvert/`:
- `1_klass_2_chetvert.html` — файл для детей, около 5 МБ;
- `1_klass_2_chetvert_uchitel.html` — сценарии для учителя, около 15 МБ.

Оба файла автономные: работают офлайн, внешних ссылок нет.

### 2.1 Файл для детей

Один `<script>` с данными и логикой (около 16 КБ кода):
- `const TITLE`, `TEACHER` (имя учительского файла);
- `APPS = [...]` — JSON-массив из **14 уроков**:
  - 7 уроков госпрограммы `g10`–`g16`, группа `«Информатика»`;
  - 7 уроков кружка `k10`–`k16`, группа `«Кружок · Paint»`.
- Поля урока: `id`, `group`, `num`, `title`, `sub`, `icon` (SVG), `teacher` (ссылка на сценарий), `screens`.
- Экраны (`screens`) — всего 419:
  - `{t:"slide", cls, html}` — **315 слайдов**. `cls` бывает `title`, `text`, `text wide`, `step`. Слайды `step` — пошаговая практика в Paint со звёздами уровня. В HTML слайда есть `s-stage` (этап урока: «Приветствие», «Постановка цели», «Теоретическая часть», «Практическая часть», «Рефлексия», «Заключение»), `s-num`, заголовок, подсказка и SVG-рисунок;
  - `{t:"type", q, pic, word, n, of}` — **43 задания «Напечатай слово»** со своей раскладкой (латинские клавиши превращаются в русские буквы);
  - `{t:"game", lv, n, stage}` — **61 уровень тренажёра**. Типы `lv.type`:
    - `story` — расставить картинки по порядку;
    - `pick` — выбрать картинку, текст или букву;
    - `train` — паровозик с пропущенными числами;
    - `nbr` — что перед и что после;
    - `word` — собрать слово из букв;
    - `groups` — разложить по группам.

    Поля уровня: `stars`, `say` (текст задания, читается голосом), `cards`, `opts`, `ok`, `seq`, `extra`, `mid`, `before`, `after`, `letters`, `word`, `pic`, `done`, `row`, `rowhl`, `show`, `dir`, `abc`, `labs`.
- `PICS = {...}` — 115 SVG-картинок по ключам: `sun`, `rain`, `seed` и т. д.;
- `ABC`, `ABCC` — буквы и их цвета;
- **78 скриншотов JPEG 1190×725** лежат в base64 в `<image id="a02" …>` внутри скрытого `<svg><defs>`. Слайды ссылаются на них через `<use href="#a02">` (150 ссылок). Сейчас все 78 картинок грузятся при открытии любого урока — для слабых ПК это нужно исправить;
- звёзды хранятся только в памяти и пропадают при закрытии;
- озвучка через `speechSynthesis` (`ru-RU`);
- поддерживается открытие урока по ссылке `?l=<id>&s=<номер экрана>`.

### 2.2 Файл для учителя

- По одному `<script type="application/json" id="d-<id урока>">` на урок: строка с полным HTML-документом сценария.
- В сценариях 161 встроенный JPEG.
- Список уроков — в `const IT = [...]`.
- В каждом сценарии есть хронометраж этапов, например для урока 10: `0–2 приветствие · 2–5 цель · 5–15 теория · 15–37 практика (9 + отдых 4 + 9) · 37–42 рефлексия · 42–45 итог`. Ещё там реплики учителя, «Перед уроком», оценивание звёздами и типичные ошибки.

## 4. Отступления от CLAUDE.md на этапе 1 (ADR-004)

Записать в `docs/decisions/004-stage1-demo.md`.

- **Только веб-часть:** `apps/server`, `apps/web`, `packages/shared`, `packages/checkers` (на этапе 1 пакет почти пустой, нужен для шага D3). Папки `apps/desktop` и `apps/agent` не создаём.
- **База — SQLite (better-sqlite3) через Drizzle вместо PostgreSQL.** Схему пишем переносимой.
- **Файлы хранятся в локальной папке `data/`** вместо S3. Папка в `.gitignore`.
- **Импортированный контент уроков** лежит в `content/` и коммитится в репозиторий. Исходники автора — в `content-src/`.
- **Один процесс Node:** API, WebSocket и раздача собранного веба на одном порту (`PORT`, по умолчанию 3000).
- **Учитель входит под демо-учёткой из сида**, без регистрации.
- **Excel-выгрузка генерируется на сервере.**
- Остальное по CLAUDE.md: TypeScript strict, Svelte 5, Fastify, zod, i18n uz/ru, бюджеты производительности, тесты.

## 5. Демо-данные

- **Школа:** «Demo School».
- **Учитель:** «Демо Учитель», логин `demo@sinf.local`, пароль из `.env` (`DEMO_TEACHER_PASSWORD`, значение по умолчанию в `.env.example`).
- **Класс 1А:** 20 вымышленных учеников (узбекские и русские имена). У каждого **код из двух картинок** из шести возможных. Картинки берутся из `PICS`, например солнце, мяч, дерево. Для классов с 3-го — код из 4 цифр.
- **Уроки:** все 14 уроков «1 класс, II четверть» из импорта. Демо-сценарий показа идёт на уроках `g10` (госпрограмма) и `k10` (Paint).
- **Викторина к уроку 10:** 5–6 вопросов с ответами-картинками из `PICS`, вопросы озвучиваются. Claude Code составляет их по слайдам урока, автор проверяет.
- **Оценивание:** звёзды. Перевод звёзд в оценку 2–5 — настройка класса, для 1А по умолчанию выключена.

## 6. Экраны (маршруты)

| Маршрут | Кто | Что |
|---|---|---|
| `/` | все | выбор: «Я учитель» / «Я ученик» |
| `/teacher/login` | учитель | вход |

| `/teacher/session/:id` | учитель | панель урока |
| `/teacher/session/:id/results` | учитель | итоги и галерея |
| `/teacher/journal/:classId` | учитель | журнал класса |
| `/teacher/demo` | учитель | виртуальные ученики, сброс демо |
| `/present/:id` | проектор | код и QR для входа, слайды, таймер, викторина, рейтинг |
| `/join` | ученик | код урока → имя → код из картинок |
| `/s/:id` | ученик | экран урока |

- Экраны ученика работают **от ширины 360 px** и рассчитаны на первоклассника: крупные кнопки, минимум текста, озвучка. Экраны учителя — **от 1366×768**.

  - акцент на светлом `#B04A12`, акцент на тёмном `#F29A55`, бирюзовый `#186B5E`;
  - основной текст `#4A5566`, приглушённый `#5E6878`;
  - шрифт системный.

    - **«Отдых» внутри практики** (9 мин + отдых 4 мин + 9 мин): экраны учеников закрываются слайдом «Отвернулись от экранов!»;
    - **демо-скорость** (1 минута урока = 6 секунд);
    - при смене этапа экраны учеников меняются сами.
  - **Готово, когда:** на демо-скорости урок 10 проходит от начала до итогов без нажатий, а переходы покрыты тестами.

- [ ] **S1.9 Презентация и проектор**
  - **Задачи:**
    - режим «Презентация»: у всех тот же экран, что у учителя, листает учитель;
    - режим «Свободно»: ученики сами идут по экранам этапа (тренажёры);
    - проектор `/present/:id` на весь экран: слайд, этап, таймер;
    - у учителя превью текущего и следующего экрана и сценарий учителя к этому этапу; листание стрелками ← →.
  - **Готово, когда:** экран у учеников меняется меньше чем за 1 секунду.

- [ ] **S1.10 Панель учителя и «Внимание!»**
  - **Задачи:**
    - плитки учеников: имя, онлайн или нет, текущий экран, звёзды, «вышел из урока», «поднял руку»; можно выделить несколько плиток;
    - «Внимание!» для всех, для выбранных и для одного ученика, с текстом (по умолчанию «Смотрите на учителя»), и снятие;
    - у ученика полноэкранный режим по кнопке «Начать»;
    - сигнал учителю, если ученик вышел из полноэкранного режима, свернул вкладку или переключился;
    - в интерфейсе учителя пометка, что в браузере блокировка «мягкая».
  - **Готово, когда:** «Внимание!» закрывает экраны выбранных учеников меньше чем за 1 секунду, а уход со вкладки виден на плитке.

- [ ] **S1.11 Практика в Paint**
  - **Задачи:**
    - на уроках кружка шаги (`step`) идут синхронно на проекторе и у учеников (или свободно — выбирает учитель);
    - у ученика кнопки «Я сделал этот шаг» и «Помогите» (поднять руку);
    - учитель видит на плитке, кто на каком шаге;
    - в конце практики учитель ставит каждому 1–3 звезды за рисунок прямо на плитке;
    - если включён S1.14 — к звёздам прикладывается скриншот.
  - **Готово, когда:** на уроке `k10` учитель видит прогресс класса по шагам и выставляет звёзды за минуту.

- [ ] **S1.12 Живая викторина**
  - **Задачи:**
    - на проекторе: вопрос, озвучка, таймер, 3–4 варианта с картинкой **и** цветом **и** буквой, счётчик ответивших;
    - у ученика большие кнопки-картинки и кнопка 🔊;
    - очки за правильный ответ — от 500 до 1000 в зависимости от скорости;
    - после каждого вопроса — правильный ответ и топ-5, в конце — пьедестал на три места;
    - результаты сохраняются в QuizAttempt;
    - викторина к уроку 10 из §5.
  - **Готово, когда:** вопросы проходят на 5 вкладках-учениках, а подсчёт очков покрыт тестами.
  - **Автор проверяет:** вопросы викторины.

- [ ] **S1.13 Итоги и журнал**
  - **Задачи:**
    - итоги сеанса: посещаемость, звёзды за тренажёры, практику и викторину;
    - оценка 2–5 по звёздам — только если включена в настройках класса;
    - журнал класса: ученики × даты уроков (звёзды, отметка присутствия);
    - экспорт в Excel на сервере: ФИО по алфавиту, дата, звёзды или оценка;
    - галерея практики: звёзды, скриншот (если есть).
  - **Готово, когда:** после урока учитель видит итоги всего класса на одном экране, а xlsx-файл открывается в Excel.

- [ ] **S1.14 Экраны через браузер (по возможности)**
  - **Задачи:**
    - на практике ученику предлагается «Показать экран учителю» (`getDisplayMedia`, с согласия; только по HTTPS и на компьютере с Chrome или Edge). Так учитель видит рисунок в Paint;
    - миниатюры 320 px раз в 3 секунды в плитках учителя: только пока открыта панель и только если картинка изменилась;
    - скриншот за N минут до конца практики и при «Я закончил» (до 1920 px, JPEG до 400 КБ) — в галерею;
    - если ученик не разрешил или устройство не поддерживает — на плитке «экран не передаётся».
  - **Готово, когда:** на HTTPS-хостинге учитель видит миниатюры трёх учеников и их скриншоты в галерее.

- [ ] **S1.15 Виртуальные ученики**
  - **Задачи:**
    - на странице «Демо» учитель добавляет в сеанс до 20 виртуальных учеников;
    - они ведут себя как живые:
      - входят с задержками;
      - проходят экраны и тренажёры с разной скоростью и разным числом звёзд;
      - иногда «уходят со вкладки» и поднимают руку;
      - отвечают в викторине со случайной скоростью и точностью около 70 %;
    - везде помечены значком «виртуальный» и удаляются при сбросе демо.
  - **Готово, когда:** учитель один показывает весь урок 10 с «живым» классом.

- [ ] **S1.16 Сборка, запуск и сценарий показа**
  - **Задачи:**
    - `pnpm build && pnpm start` запускает всё на одном порту; Dockerfile;
    - в README два варианта запуска:
      - а) на ноутбуке учителя в локальной сети (адрес вида `http://192.168.x.x:3000`, без функций экрана);
      - б) на хостинге с Node.js, WebSocket и HTTPS;
    - `docs/demo-script.md` — сценарий показа на 10 минут на уроках `g10` и `k10`:
      - что открыть на проекторе;
      - что делают 2–3 живых ученика;
      - когда включить виртуальных учеников;
      - какие кнопки нажимать по порядку;
    - чек-лист перед показом: зарядка, сеть, сброс демо, демо-скорость.
  - **Готово, когда:** автор по README запускает демо у себя и проводит пробный показ по сценарию.
