# Проверка этапа 6 и тест на ПК

Что пройти руками после этапа 6 (`STAGE6.md`). Разделы пишутся по ходу шагов; пошаговая
установка на ПК (онлайн и офлайн) — в разделе «Тест на ПК», он появится в шаге B8.

## 1. Отчёты (5 минут, B1)

1. Администратор: страница школы → «Отчёты». **Должно быть:** период «01.09.<год> — сегодня»,
   строка каждого класса и каждой параллели: ученики, уроки, посещаемость, средний балл, 5/4/3/2,
   КТП.
2. Сверить одну строку с журналом класса: та же средняя оценка, столько же уроков.
3. Поставить период «С — По» на неделю — цифры меняются. «Учебный год» — обратно.
4. «Скачать Excel» — файл открывается, классы и параллели на месте.
5. Учитель: страница класса → «Отчёт» → по каждому ребёнку; «Скачать Excel».

## 2. Лицензии (10 минут, B2)

Нужен суперадмин: `SUPERADMIN_EMAIL` и `SUPERADMIN_PASSWORD` в `.env` сайта.

1. Суперадмин → `/admin`: у каждой школы — состояние лицензии. «Лицензия…» → выдать новой школе,
   например 2 класса до конца мая.
2. Администратор школы: «Обзор» → карточка «Лицензия: действует, классов 0 из 2».
3. Учитель школы создаёт классы: третий — отказ «Школа заняла все 2 классов…».
4. Отозвать лицензию → на ПК класса урок не начинается: «У школы нет действующей лицензии».
5. Учитель без школы: первый личный класс — да, второй — «Бесплатно — один личный класс».

## 3. Английский интерфейс (3 минуты, B3)

1. Главная страница → переключатель языка справа вверху → «English»: «I’m a student», «I’m a teacher».
2. Обновить страницу — язык остался английским.
3. Вход учителя, журнал, КТП, отчёты — по-английски; «Download Excel» в журнале даёт файл
   `gradebook-…xlsx` с английскими заголовками.
4. Уроки и критерии практики остаются на русском (их пишут на русском и узбекском) — так и задумано.
5. Обратно — «Русский» или «O‘zbekcha».

## 4. Слайды из PowerPoint (5 минут, B4)

1. Учитель → «Мои уроки» → новый урок → этап «Теория» → «Слайды из PowerPoint» → любая своя
   презентация `.pptx`.
2. Слайды появились по порядку: заголовки, текст, пункты списком, картинки. Их можно править.
3. «Просмотр» — слайды в стиле Sinf (не как в PowerPoint: так задумано). Если нужен точный вид —
   «Файл → Сохранить как → PDF» в PowerPoint и «Слайды из PDF».
4. Старый файл `.ppt` — сообщение «нужна презентация PowerPoint (.pptx)».

## 5. Практика в Scratch, Arduino, Python (15 минут, B5)

В браузере (без ПК класса):

1. Учитель → «Задания практики» → «Программа»: Python. «Добавить проверку» → «Используется: цикл
   for», «Объявлена функция», «Выводит текст», «Скобки, двоеточия и отступы в порядке».
2. «Эталон» — свой `.py` → «Проверить»: видно, что прошло, и что сервер согласен. Уберите двоеточие
   после `if` — «строка N: нет двоеточия».
3. То же для Scratch (`.sb3` из Scratch 3) и Arduino (`.ino`).

На ПК класса (нужны программы, поставленные **для всех пользователей**):

4. Поставьте Scratch 3, Arduino IDE 2 и Thonny (или Python с IDLE) на ПК ученика.
5. Урок с практикой Python (шаблон `.py`): у ученика плитка «Python» открывает Thonny с файлом; после
   «Сохранить» учитель видит счёт критериев.
6. Практика Arduino: IDE открывается без вопроса «переместить файл в папку?»; сохранение доходит до
   учителя как `blink.ino`.
7. Без установленной программы её плитки у ученика нет.

## 6. Автообновление (20 минут + ожидание, B6)

**Один раз, до сборки** (без этого сборки ставятся, но не обновляются):

1. На своём компьютере: `node tools/update-key.mjs`.
2. GitHub → репозиторий → Settings → Secrets and variables → Actions:
   - вкладка **Secrets** → New repository secret `SINF_UPDATE_KEY` — первая строка-ключ;
   - вкладка **Variables** → New repository variable `SINF_UPDATE_PUBLIC_KEY` — вторая.
   - По желанию ту же вторую строку — в `.env` сайта как `UPDATE_PUBLIC_KEY`.
   Секретный ключ больше никуда не кладите; потеряете — ПК со старой программой обновления новых
   версий не примут (придётся переставить с флешки).
3. Перезапустите сборку «Windows app» (Actions → Run workflow) — у неё появится артефакт
   `Sinf-update-x64`.

**Проверка:**

4. Поставьте ПК учителя и ПК ученика из `Sinf-setup-x64` **этой** сборки; на ПК учителя свяжите его
   с сайтом (как в разделе про онлайн).
5. Сделайте ещё одну сборку (любой коммит или Run workflow) — у неё номер больше.
6. Суперадмин → `/admin` → «Обновления Windows-приложения» → `update.json` и `Sinf-update-….exe`
   из артефакта `Sinf-update-x64` новой сборки → «Загрузить».
7. Откройте Sinf на ПК учителя (он заберёт обновление с сайта при обмене, до 10 минут). Не начинайте
   урок.
8. В течение получаса (или сразу: в командной строке администратора
   `"C:\Program Files\Sinf\Sinf.Updater.exe" --now`) ПК учителя, затем ПК ученика ставят новую
   версию сами: окно Sinf закроется и откроется снова. Версия видна в «Компьютеры» на сайте.
9. Во время урока обновление **не ставится** — проверьте: начните урок, запустите `--now`, в
   ответе `WaitForLesson`.
10. Журнал: `C:\Program Files\Sinf\updates\updater.log`; что программа решила бы сейчас —
    `Sinf.Updater.exe --status`.

## 7. Агент — закрытая среда (30 минут, B7) — **только на запасном ПК или в виртуальной машине**

Агент глубоко меняет Windows. Проверьте его сначала там, где не жалко: виртуальная машина
(Hyper-V, VirtualBox) с Windows 10/11 Pro или лишний ПК. Перед проверкой узнайте пароль своей
учётки администратора — он понадобится, чтобы войти после включения агента.

1. Установка: `Sinf-setup-….exe` → «Компьютер ученика» → имя ПК → галочка **«Включить закрытую
   среду (агент)»**. Или тихо: `Sinf-setup-….exe /VERYSILENT /ROLE=student /PC=ПК-01 /AGENT=1`.
2. Командная строка администратора: `"C:\Program Files\Sinf\Sinf.Agent.exe" status` — `enabled:
   True`, `service: Running`, `account: Ученик`, `secret: True`, `shell: …Sinf.exe`.
3. Перезагрузка → Windows **сама** входит в «Ученик», вместо рабочего стола — Sinf (ищет учителя).
4. Попробуйте выбраться (`docs/escape-checklist.md`): Ctrl+Alt+Del — нет диспетчера задач,
   блокировки, выхода, смены пароля; Win+R — ничего.
5. **Сторож:** если удалось закрыть Sinf (например, `taskkill` из сеанса администратора:
   `taskkill /F /IM Sinf.exe`), он появляется снова за 1–3 секунды.
6. **Блокировка держится:** учитель жмёт «Внимание!» → убейте Sinf → он поднимается уже с закрытым
   экраном; «Снять» у учителя открывает.
7. **Обслуживание:** Ctrl+Alt+Shift+F12 → пароль выхода → «Выйти из Sinf» → открывается обычный
   рабочий стол, 30 минут Sinf не возвращается. Ctrl+Alt+Del → «Сменить пользователя» → своя учётка
   администратора.
8. **Откат:** из учётки администратора `"C:\Program Files\Sinf\Sinf.Agent.exe" disable` (или
   удаление Sinf; с `/REMOVEACCOUNT=1` — и учётки «Ученик») → перезагрузка: обычный вход
   Windows, никакого автовхода, у «Ученика» снова обычный рабочий стол.
9. Если что-то пошло не так и в администратора не войти: безопасный режим Windows (там агент не
   работает, а автовход отключён) → `Sinf.Agent.exe disable`.
