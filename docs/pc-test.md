# Проверка этапа 6 и тест на ПК

Что пройти руками после этапа 6 (`STAGE6.md`). Разделы пишутся по ходу шагов; пошаговая
установка на ПК (онлайн и офлайн) — в разделе «Тест на ПК», он появится в шаге B8.

## 1. Отчёты (5 минут, B1)

1. Администратор: страница школы → «Отчёты». **Должно быть:** период «01.09.<год> — сегодня»,
   строка каждого класса и каждой параллели: ученики, уроки, посещаемость, средний балл, 5/4/3/2,
   КТП.
2. Сверить одну строку с журналом класса: та же средняя оценка, столько же уроков.
3. Поставить период «С — По» на неделю — цифры меняются. «Учебный год» — обратно.
4. «Скачать Excel» — файл открывается, классы и параллели на месте.
5. Учитель: страница класса → «Отчёт» → по каждому ребёнку; «Скачать Excel».

## 2. Лицензии (10 минут, B2)

Нужен суперадмин: `SUPERADMIN_EMAIL` и `SUPERADMIN_PASSWORD` в `.env` сайта.

1. Суперадмин → `/admin`: у каждой школы — состояние лицензии. «Лицензия…» → выдать новой школе,
   например 2 класса до конца мая.
2. Администратор школы: «Обзор» → карточка «Лицензия: действует, классов 0 из 2».
3. Учитель школы создаёт классы: третий — отказ «Школа заняла все 2 классов…».
4. Отозвать лицензию → на ПК класса урок не начинается: «У школы нет действующей лицензии».
5. Учитель без школы: первый личный класс — да, второй — «Бесплатно — один личный класс».
