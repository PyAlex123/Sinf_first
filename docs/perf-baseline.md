# Замеры на железе (шаг 0.3 `PLAN.md`)

Бюджеты — `CLAUDE.md` §3.1. Цифры снимаются на настоящих ПК по ходу этапа 3 (`STAGE3.md`).

## Как мерить

- **ОЗУ:** Диспетчер задач → «Подробности». Сложить `Sinf.exe` и все `msedgewebview2.exe` этого
  окна (у ученика `node.exe` нет; у учителя прибавить `node.exe`).
- **Процессор в простое:** урок открыт, ничего не происходит минуту; среднее по тем же процессам
  (Монитор ресурсов → ЦП → поставить галочки на процессы).
- **Холодный старт:** перезагрузить ПК, запустить `Sinf.exe`, засечь время до экрана входа ученика
  (или панели учителя).
- **Захват экрана (H5):** процессор ученика, пока у учителя открыта панель класса.
