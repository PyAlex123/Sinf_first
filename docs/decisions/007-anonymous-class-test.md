# ADR-007: анонимные участники урока до входа учеников

- **Статус:** принято (временно, до S1.7)
- **Дата:** 2026-11-12
- **Связано:** `STAGE1.md` S1.6–S1.7, ADR-006, `docs/stage1-architecture.md` §9

## Контекст

Автору нужно проверить синхронный урок с настоящим классом раньше, чем будут готовы вход учеников по кодам из картинок, карточки и рассадка (S1.6–S1.7). Для проверки важны: выбор класса на сайте, синхронные экраны, «Внимание!», плитки учеников у учителя, игры со звёздами.

## Решение

1. Ученик входит без имени и кода: `/join` → класс → `/s/<сеанс>`. Сервер выдаёт ему **анонимного участника** с номером («Ученик 3») и секретным токеном; токен хранится в `sessionStorage`, поэтому перезагрузка страницы возвращает того же участника с его звёздами. Закрытие вкладки — новый участник.
2. В `SessionState.participants` у анонимного участника `studentId = null`. Звёзды считаются в сеансе и видны учителю, но **в журнал не попадают** (нет ученика). Таблица `screen_results` остаётся для S1.7.
3. Для выбора класса публичный `GET /api/join/classes` отдаёт классы и их активный сеанс; в базе сейчас один класс 1А.
4. После S1.7 вход по коду заменит анонимный режим: участник получит `studentId`, и те же сообщения протокола (`participant.updated`) понесут имя вместо номера. Страницы `/join` и `/s/:id` остаются, меняется только шаг входа.

## Технические решения, принятые по ходу

- **ESLint для Svelte** (`eslint-plugin-svelte` с `svelte-eslint-parser`) и Prettier (`prettier-plugin-svelte`), чтобы правила CLAUDE.md §9 действовали и в `.svelte`. Правило `svelte/no-at-html-tags` выключено: HTML уроков очищается при импорте (ADR-005).
- **CSS автора ограничен классом `.lesson-root`** при импорте (`scope-css.ts`), чтобы не влиять на интерфейс платформы.
- **Оптимистичное обновление экрана у учителя**: быстрые нажатия `→` считаются от нового экрана, не дожидаясь эха сервера.
- **Два варианта запуска** (`docs/deploy.md`): ноутбук в локальной сети и Docker + Caddy на сервере с доменом.

## Последствия

- На уроке класс видит «Ученик 1…N», а не имена; учитель узнаёт детей по номерам на экранах.
- Журнал и посещаемость по этому тесту не заполняются — это ожидаемо до S1.7.
