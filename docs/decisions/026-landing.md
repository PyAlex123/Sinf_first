# ADR-026. Лендинг и заявка на пилот

- **Статус:** принято (этап 6, шаг B10; PLAN.md 8.4; решения автора от 2026-11-23: «главная и
  заявка», «контактов нет, только форма»)
- **Связано:** CLAUDE.md §1, §2, §3.4, §4.11; ADR-009 (суперадмин), ADR-021 (почта)

## Решение

- **Главная `/` на сайте — лендинг** (`apps/web/src/pages/Landing.svelte`):
  - первый экран с макетом панели учителя (нарисован на CSS, без картинок);
  - «Что внутри» — пять частей продукта из §1;
  - «Как проходит урок» — этапы из §4.3;
  - «В браузере и в классе» — честная таблица из §4.11: в браузере блокировки ввода нет;
  - тарифы, заявка на пилот, вопросы, подвал со ссылками на вход, регистрацию, вход ученика и
    «Мои работы».
- **На сервере класса** (ПК учителя: `CLASSROOM_MODE` или связь с сайтом) `/` — прежняя простая
  страница с крупными кнопками. Дети в кабинете рекламу не видят. Какой это сервер, веб узнаёт по
  `GET /api/site`; пока ответа нет, не рисуется ничего, чтобы одна страница не мелькала перед другой.
- **Лендинг — отдельный чанк** (около 5 КБ gzip), начальный бандл не растёт. Веб-шрифтов, картинок
  и анимаций нет (§3.1).
- **Цен нет.** §2: «цены определим позже». Тариф школы — «лицензия на класс в год, цену называем по
  заявке», учителю — «бесплатно».
- **Ничего не выдумано.** Текст взят из CLAUDE.md. Нет числа школ, отзывов, замеров и обещания о
  сервере в Узбекистане (это ещё решается с юристом, §3.4). Про слабые компьютеры — «рассчитано на»,
  а не цифры.
- **Контактов нет** (решение автора): связь — через форму. Добавить телефон или Telegram — по слову
  автора.
- **Заявка на пилот:**
  - поля: школа, город, имя и должность, как связаться, сколько классов, комментарий;
  - таблица `pilot_requests` (миграция 0021); `POST /api/pilot-requests` без входа, только на
    сайте (на сервере класса — 404);
  - защита: не больше 3 заявок в час с одного адреса и скрытое поле-ловушка (робот, заполнивший
    его, получает «спасибо», но ничего не сохраняется);
  - письмо суперадмину через почту сайта (ADR-021; без `SMTP_URL` — в журнал сервера);
  - суперадмин видит заявки в `/admin` («Заявки на пилот»): новые сверху, «Обработано» и
    «Вернуть в новые».
- **Узбекский текст** написан без носителя языка — его стоит вычитать.

## Что не сделано

- Отдельные страницы «Школам» и «Учителям», блог, поисковая оптимизация с отрисовкой на сервере
  (сейчас страница рисуется в браузере; поисковики, которые выполняют JavaScript, её видят).
- Цены, контакты, реквизиты, договор и счёт (PLAN 8.3) — по решению автора.
