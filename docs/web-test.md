# Проверка веба этапа 4 (уроки учителя, журнал, КТП)

Чек-лист для автора (`STAGE4.md`, раздел 5). Достаточно браузера: сайт (`pnpm build && pnpm start`
или сервер) и, для разделов с уроком, второе окно или телефон в роли ученика. Что было «не так» —
по номерам пунктов.

## 1. Свой урок и конструктор (10 минут, W1–W2)

1. Главная учителя → **«Мои уроки»** → «Новый урок» → название «Клавиатура и мышь», класс → шаблон
   на 45 минут → «Создать и открыть».

   **Должно быть:** открылся конструктор, вверху полоса этапов «Теория 10 · Практика 25 · Викторина
   7 · Итоги 3», «Всего: 45 мин».
2. В теории «+ Слайд». Заполнить:
   - заголовок;
   - два абзаца (между ними пустая строка);
   - список из трёх пунктов;
   - картинка с телефона или фото (2–5 МБ).

   **Должно быть:**
   - картинка появилась за пару секунд;
   - вверху справа «Сохранено»;
   - кнопки «Сохранить» нет — сохраняется само.
3. Поставить галочку «Приветствие». **Должно быть:** этап встал первым, «Всего: 50 мин» (красным,
   «урок обычно 45 мин»).
4. «Просмотр». **Должно быть:** урок на весь экран, как его увидит класс; на слайде абзацы, список
   и картинка; стрелками листается. Закрыть — «Закрыть» или Esc.
5. Обновить страницу. **Должно быть:** всё на месте.
6. Открыть тот же урок во второй вкладке, поменять там название, вернуться в первую и поменять
   что-нибудь. **Должно быть:** в первой — «Урок изменён в другой вкладке…», ничего не затёрто.
7. Главная → у урока «Начать» с классом. **Должно быть:**
   - урок идёт, как уроки автора: этапы, таймер, слайды у ученика;
   - кнопки «Сценарий» нет.
8. «Кто видит» → «для школы». Войти другим учителем той же школы → «Уроки школы». **Должно быть:**
   урок в списке, «Копировать себе» делает свою копию.

## 2. Слайды из PDF (5 минут, W3)

1. Любую свою презентацию PowerPoint сохранить как PDF: «Файл → Сохранить как → PDF».
2. Конструктор → этап «Теория» → **«Слайды из PDF»** → выбрать файл.

   **Должно быть:**
   - «Страница N из M», для 20–30 страниц — меньше минуты;
   - каждая страница стала слайдом;
   - «Просмотр» показывает страницы во весь экран, текст читается.
3. Записать, сколько секунд заняло и на каком компьютере.

## 3. Тест (10 минут, W4)

1. Конструктор → этап «Теория» → «Куда смотрят ученики» → «В свой компьютер». Добавить три вопроса:
   - один верный вариант;
   - несколько верных;
   - ввод ответа (два варианта написания, например «Enter» и «Энтер»).

   Пока вопрос не дописан, красным подсказано, чего не хватает.
2. Начать урок; ученик входит в браузере или на ПК класса. **Должно быть:**
   - у ученика «Вопрос 1 из 3»;
   - после «Ответить» — «Верно!» или «Не совсем так. Ответ принят», изменить ответ нельзя;
   - у учителя на плитке «Тест: 1 из 3».
3. Ученик обновляет страницу. **Должно быть:** «Ответ уже принят».
4. Завершить урок → итоги. **Должно быть:** столбец «Тест» (★ сколько верно из скольких), оценка
   считается с ним.

## 4. Практика и викторина в своём уроке (15 минут, W5)

1. Конструктор → этап «Практика» → **«+ Задание практики»**.
   - Программа Word, имя файла, 2–3 проверки (заголовки, шрифт, таблица) и один ручной критерий.
   - «Загрузить шаблон» — свой .docx.
   - «Проверить эталон» — правильно оформленный файл. **Должно быть:** все проверки «да».
2. Этап «Рефлексия» → **«Живая викторина»** → два вопроса с ответами словами.
3. Провести урок с учеником (браузер или ПК класса). **Должно быть:**
   - на практике у ученика ваш шаблон;
   - после сохранения или сдачи — счёт;
   - на рефлексии викторина начинается сама, ответы словами читаются на кнопках и на проекторе.
4. Итоги: критерии, ручные отметки и оценка — как в разделе 4ж `docs/hardware-test.md`.

## 5. Сообщение и «открыть у всех» (5 минут, W6)

1. Урок, двое учеников в браузере. Панель → «Сообщение классу»:
   - текст «Откройте сайт урока» и ссылка `https://…` → «Всем»;
   - **должно быть:** у обоих карточка с текстом и «Открыть ссылку»; ссылка открывается в новой
     вкладке, урок остаётся.
2. Выбрать на плитке одного ученика → сообщение → «Выбранным». **Должно быть:** только у него.
3. Режим «Свободно»: ученики листают сами. Учитель переходит на другой экран → «Открыть этот экран
   у всех». **Должно быть:** у всех этот экран.
4. На ПК класса ссылка показывается текстом: «в приложении класса сайты не открываются».

## 6. Программа (10 минут, W7)

1. Главная → «Программа класса» → «Программы» → создать «1 класс, информатика».
2. Во 2 четверть добавить три урока: два авторских и один свой. Поменять порядок стрелками,
   один урок перенести в 3 четверть. «Сохранить».
3. Главная → «Выбрать программу». **Должно быть:** «Следующий урок» — первый урок программы, кнопка
   «Начать».
4. Провести его (можно сразу завершить). **Должно быть:** следующий — второй, «Пройдено уроков: 1
   из 3».
5. На ПК класса (после связи с сайтом) — тот же следующий урок, даже без интернета.

## 7. Библиотека (10 минут, W8)

1. Свой урок → «Кто видит» → «в библиотеке».
2. Войти другим учителем (можно зарегистрировать нового) → главная → «Библиотека». **Должно быть:**
   - урок в списке; находится по слову из названия или темы (в любом регистре, «е» вместо «ё»);
   - фильтр по классу работает.
3. «Открыть» — урок листается. «Копировать себе» — открылся конструктор, урок в «Мои уроки», правки
   не задевают оригинал.
4. «Пожаловаться» на урок. Войти суперадмином (`SUPERADMIN_EMAIL`) → `/admin` → «Жалобы на
   библиотеку» → «Скрыть из библиотеки». **Должно быть:** урок пропал из библиотеки, у автора
   остался.

## 8. Журнал (10 минут, W9)

1. Журнал класса → «Столбец без урока» → дата, «Контрольная» → «Добавить столбец».
2. Щёлкнуть первую клетку и, не трогая мышь, оценить весь класс: 2–5 (курсор идёт вниз сам), «н» —
   кто не был. Засечь время: цель — меньше минуты на 30 человек.
3. «к» на клетке — комментарий. **Должно быть:** оценка подчёркнута пунктиром, текст при наведении.
4. В столбце прошедшего урока поставить оценку и комментарий; Backspace стирает оценку, комментарий
   остаётся.
5. Обновить страницу — всё на месте; «Скачать для eMaktab (Excel)» — со столбцом «Контрольная».
6. На ПК класса без интернета поставить оценку в такой столбец; после связи — она на сайте. Поменять
   её на сайте — после связи на ПК новая.

## 9. Импорт КТП (10 минут, W10)

1. Главная → «КТП» → «Загрузить КТП». Выбрать класс, свой **настоящий** КТП из Excel.
2. **Должно быть:** найдена таблица и строка заголовка, колонки «№», «Тема», «Часы», «Неделя / дата»,
   «Примечание» выбраны сами; даты — как в Excel (`03.09.2026`, а не `46268`).
3. Посмотреть предпросмотр: строки «I четверть» и пустые — «пропущено», часы не числом — подсвечены.
   Поправить колонку руками (например, взять «Неделю» вместо «Даты») — таблица меняется сразу.
4. «Сохранить N тем» → открывается план. «Выгрузить в Excel» — файл открывается, темы на месте.
5. То же со своим КТП из Word (кружок). Если таблица не та — выбрать другую в «Таблица».
6. Старый `.doc`/`.xls` или файл с паролем — понятная подсказка «сохраните заново».
7. **Прислать:** КТП, которые не прочитались или прочитались криво (сам файл или его копию без
   фамилий).
