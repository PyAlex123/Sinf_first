# Чек-лист побега из киоска (шаг 0.2 `PLAN.md`, этап 3 — H3)

Проверяется на **ПК ученика**: `Sinf.exe`, роль «Компьютер ученика», окно открыто на экране входа или
в уроке. Колонка «Ожидаем» — что должно быть после H3. Колонку «Результат» заполняет автор на железе:
**закрыто**, **не закрыто** (и что произошло) или **как закрыть**.

Чем закрываем:

- **хук** — низкоуровневый перехват клавиатуры в окне ученика (`KeyboardGuard`, правила `KeyRules`);
- **окно** — поверх всех окон, забирает фокус назад, не закрывается без пароля;
- **WebView2** — без DevTools, меню, клавиш браузера, новых окон, загрузок и перетаскивания;
- **белый список** — открываются только `/join` и `/s/<id>` у учителя (и в C#, и в веб-роутере);
- **специальные возможности** — горячие клавиши залипания, фильтрации и озвучки выключены на время
  киоска и возвращаются при выходе;
- **агент (6.4)** — служба Windows и политики; **до неё пункт остаётся открытым**.

## Клавиши Windows

| Что нажать | Ожидаем | Чем | Результат |
|---|---|---|---|
| Win | ничего не открывается | хук | |
| Win+D, Win+E, Win+R, Win+Tab, Win+X | ничего | хук | |
| Win+L | **экран блокировки** — открыто | агент (6.4) | |
| Alt+Tab, Alt+Esc | окно не переключается | хук | |
| Ctrl+Esc | меню «Пуск» не открывается | хук | |
| Alt+F4 | окно не закрывается | хук + окно | |
| Alt+Space | системное меню окна не появляется | хук | |
| Ctrl+Shift+Esc | диспетчер задач не открывается | хук | |
| Ctrl+Alt+Del → диспетчер задач, смена пользователя, выход, блокировка, смена пароля | **открыто** (без агента диспетчер задач нарочно выходит поверх киоска — находка 3; запрещает его агент) | агент (6.4) | |
| 5 раз Shift (залипание) | окно «Залипание клавиш» не появляется | специальные возможности | |

| Win+U (специальные возможности) | ничего | хук | |

## Окно урока (WebView2)

| Что сделать | Ожидаем | Чем | Результат |
|---|---|---|---|
| Правый клик | меню нет | WebView2 | |

## Процесс и система

| Что сделать | Ожидаем | Чем | Результат |
|---|---|---|---|
| Кликнуть мимо окна, свернуть | окно возвращается наверх за 0,3 с | окно | |
| Закрыть `Sinf.exe` через диспетчер задач (если открылся через Ctrl+Alt+Del) | **окно закрывается, никто не поднимает** — открыто | агент (6.4): watchdog | |
| `Sinf.exe --setup` или `--dev` | просит пароль администратора | окно | |
| Запустить другую программу (через Ctrl+Alt+Del → диспетчер → «Запустить задачу») | **открыто** | агент (6.4): наблюдатель процессов | |
| «Файл → Открыть / Сохранить» в программе, диски `C:\`, папки других | **не проверяется на H3**: программ ещё нет | H6, папка — 6.8 | |
| Флешка с exe | **открыто** | агент (6.4) | |

## «Внимание!» (H4)

| Что сделать | Ожидаем | Результат |
|---|---|---|
| Учитель: «Внимание всем» | на ПК ученика не печатается, мышь не двигается, клики не проходят | |
| Под «Внимание!»: Alt+Tab, Win, Ctrl+Esc | ничего | |
| Учитель: «Снять у всех» | ввод вернулся | |
| «Внимание!» одному ученику с плитки | заблокирован только он | |
| Под «Внимание!»: Ctrl+Alt+Shift+F12 | окно пароля, в нём можно печатать и кликать | |
| Под «Внимание!»: Ctrl+Alt+Del → снять Sinf | **блокировка пропадает** — открыто до агента (6.4) | |

## Paint на практике (H6)

| Что сделать | Ожидаем | Результат |
|---|---|---|
| «Открыть Paint» на практике | открылся Paint, в нём можно рисовать | |
| В Paint: Win, Alt+Tab, Alt+F4 | ничего | |

| Панель сверху: «Вернуться к уроку», потом «Вернуться в Paint» | переключается туда и обратно | |

## Выход для администратора

| Что сделать | Ожидаем | Результат |
|---|---|---|
| Ctrl+Alt+Shift+F12 | окно пароля поверх всего | |
| Неверный пароль 5 раз | «Подождите минуту», даже верный пароль не принимается | |
| Верный пароль → «Выйти из Sinf» | киоск закрыт, специальные возможности вернулись к прежним | |
| Верный пароль → «Сменить настройки» | окно роли; после «Готово» Sinf перезапускается с новой ролью | |
| ПК ученика, ещё ни разу не нашедший учителя | Ctrl+Alt+Shift+F12 выпускает **без пароля**: пароля он ещё не знает (время настройки) | |
