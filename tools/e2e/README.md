# Сквозные сценарии

Этими скриптами закрывался каждый шаг планов: они поднимают настоящий браузер (Playwright),
проходят путь учителя и учеников и печатают список проверок с числами. Это не модульные тесты
(`pnpm test`) — это проверка того, что всё вместе работает как на уроке.

## Как запускать

```bash
pnpm build
pnpm start            # сервер на :3000 с демо-данными
node tools/e2e/s110.cjs
```

Снимки экрана и временные базы складываются в `tools/e2e/out/` (в git не попадает). Сценарии
рассчитаны на свежие демо-данные: если база «поехала», проще стереть `data/` и запустить сервер
заново (демо-класс создаётся сам).
