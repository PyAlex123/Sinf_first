# Сквозные сценарии

Этими скриптами закрывался каждый шаг планов: они поднимают настоящий браузер (Playwright),
проходят путь учителя и учеников и печатают список проверок с числами. Это не модульные тесты
(`pnpm test`) — это проверка того, что всё вместе работает как на уроке.

## Как запускать

```bash
pnpm build
pnpm start            # сервер на :3000 с демо-данными
node tools/e2e/s110.cjs
```

Снимки экрана и временные базы складываются в `tools/e2e/out/` (в git не попадает). Сценарии
рассчитаны на свежие демо-данные: если база «поехала», проще стереть `data/` и запустить сервер
заново (демо-класс создаётся сам).

## Что проверяет каждый

| Скрипт | Шаг | Что проверяет |
|---|---|---|
| `demo-check.cjs` | демо | демо-учитель видит класс 1А, 20 учеников с картинками-кодами, урок запускается |
| `s21.cjs` | S2.1 | регистрация нового учителя, чужие классы и уроки не видны (404), демо-вход работает |
| `s22.cjs` | S2.2 | создание класса, вставка списка из Excel, правка и удаление ученика, печать карточек |
| `s23.cjs` | S2.3 | суперадмин создаёт школу, учитель подаёт заявку, директор принимает и исключает |
| `s24.cjs` | S2.4 | школа добавляет компьютер, привязка по коду, отклик, отвязка убивает токен |
| `s26.cjs` | S2.6 | **два сервера**: облако и школьный ПК. Урок без связи → очередь → связь → урок в облаке, повтор не задваивает |
| `s110.cjs` | S1.10 | «Внимание» одному и всем, снятие, рука, счётчик выходов, замер задержки |
| `s110b.cjs` | S1.9 | свободный режим: стрелки листают урок, за шторкой — нет |
| `s111.cjs` | S1.11 | практика в Paint: шаги у ученика, прогресс и звёзды на плитке учителя |
| `s112.cjs` | S1.12 | живая викторина на пятерых: старт с этапом, очки за скорость, рейтинг, пьедестал |
| `s113.cjs` | S1.13 | итоги g10 и k10, галерея рисунков, журнал по алфавиту с «н», выгрузка Excel, переключатель «звёзды → оценка», журнал по-узбекски |
| `s115.cjs` | S1.15 | учитель один: 20 виртуальных учеников входят по одному, практика на ×10, руки и уходы, викторина ~70 %, значки в итогах и журнале, сброс демо |
| `s116.cjs` | S1.16 | пробный показ по `docs/demo-script.md`: сброс демо, двое живых по QR и картинкам, 18 виртуальных, презентация, «Внимание!», практика, викторина, итоги, Excel, k10 с шагами и звёздами за рисунок |
| `h1.cjs` | H1 | окно ученика (подставленный мост `sinfHost`, роль `student`): страница входа показывает имя ПК; в обычном браузере его нет |
| `shots.cjs` | — | снимки 18 экранов для сравнения «до/после»: `node tools/e2e/shots.cjs tools/e2e/out/before` |

`s26.cjs` поднимает свои серверы сам (порты 3300 и 3400) — для него отдельный `pnpm start` не нужен,
нужен только `pnpm build`.
